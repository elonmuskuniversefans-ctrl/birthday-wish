# Birthday Wish Website

Interactive birthday website with music, animations and fireworks.

## Make it live with ZERO branding (Recommended)

1. Open this link: https://github.com/elonmuskuniversefans-ctrl/birthday-wish/settings/pages
2. Under **Source** → Select **Deploy from a branch**
3. Branch: **main**
4. Folder: **/ (root)**
5. Click **Save**

After 1-2 minutes your clean website will be live at:

### https://elonmuskuniversefans-ctrl.github.io/birthday-wish/

No badge, no notification, fully premium look.
